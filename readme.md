# Game

Run locally:

```bash
python3 -m http.server 8000
```

## Gameplay

- Each game loads against a random enemy.
- Reload the page to load another enemy or restart the game.
- To start, choose an action and complete the minigame.
- You can equip passive effects (they trigger when certain conditions are met) or active effects (still not fully completed).

## Mecha Customization

- To customize your mecha, edit `robot1` in `js/app.js` and replace its parts with different ones from `js/parts.js`.
